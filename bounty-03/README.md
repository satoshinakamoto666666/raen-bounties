# `raen-crewai-tools` — CrewAI `@tool` Wrappers for RAEN MCP Gateway (BOUNTY-03)

Single-file importable and `pip`-installable CrewAI `@tool` wrappers (`dispute_letter` and `contract_analyze`) backed by the **RAEN MCP Gateway** (`https://raen-mcp-gateway.fly.dev/mcp`).

## Installation

```bash
pip install ./bounty-03
export RAEN_MCP_API_KEY="your_raen_mcp_bearer_key"
```

## Quickstart & Example Crew Flow

```bash
python bounty-03/example_crew.py
```
